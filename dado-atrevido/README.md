# Dado Atrevido

Juego para parejas adultas (+18) en el navegador del móvil: cada uno tira el dado por turnos y, en lugar de números, sale **Verdad**, **Reto** o **Prenda** (fuera una prenda). Quien no quiere cumplir, bebe y pasa el turno.

**Juega aquí:** https://jrubioadies.github.io/dado-atrevido/

- Tres niveles: suave, picante y muy picante, con cartas que no se repiten hasta agotar el mazo.
- Cada uno empieza con 3 a 7 prendas; cuando se acaban, la cara de Prenda se convierte en un reto.
- Castigo a elegir: un trago, un chupito o sin alcohol.
- Un solo móvil que os vais pasando; la partida se guarda en el navegador.

Un único `index.html` en JavaScript puro, sin librerías.
