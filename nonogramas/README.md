# Nonogramas

Pinta las casillas con las pistas y descubre el dibujo oculto.

**Juega aquí:** https://jrubioadies.github.io/nonogramas/ · **Versión completa:** https://games.adilcotech.com/?juego=nonogramas

Un único `index.html` en JavaScript puro, sin librerías, pensado para el móvil: tema claro y oscuro y partida guardada en el navegador.

`index.html?reel` abre el modo de grabación vertical (1080×1920) con una partida guionizada y determinista; `render_reel.py` la graba con Playwright y ffmpeg monta el vídeo de Instagram.
