Resuelto

Cada número es un bloque de casillas seguidas rellenas en esa fila o columna, en ese orden y con al menos un hueco entre bloques. Rellenar pinta la casilla; Marcar pone una X donde sabes que no hay nada. Arrastra el dedo para pintar varias seguidas (o marca con clic derecho). Las pistas se atenúan al cumplirse. Con teclado: flechas, espacio para rellenar, X para marcar y Z para deshacer. Cada puzle tiene una sola solución y tu progreso se guarda solo.
